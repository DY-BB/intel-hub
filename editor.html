使用说明

这个编辑器是干什么的？

它是你本地的「私密数据编辑工具」。你在这里修改三类数据（检索词库 / 术语表 / 每日情报），然后导出完整的 data.js，替换掉项目里的 data.js 后提交到 GitHub，网站即可更新。

工作流程
  1. 解锁进入
  2. 切换到对应 Tab，修改 JSON 内容
  3. 点「格式化校验」确认 JSON 合法
  4. 点「导出 data.js」下载完整文件
  5. 用下载的 data.js 替换项目里的同名文件，提交到 GitHub
⚠️ 重要安全提示

本 editor.html 不要上传到公开的 GitHub 仓库。因为它是纯前端页面，密码写在代码里，懂技术的人查看源码即可绕过。正确做法是：editor.html 只保留在你本地电脑，仓库里只放 index.html / app.html / data.js / models.js 这四个公开文件。这样访客只能看到静态页面，无法修改任何数据。

修改默认密码

打开 editor.html，找到脚本开头的 const PASSWORD = 'love.atsp2';，改成你自己的密码即可。
